# Documentation Reviewer

Check that a new contributor can reproduce the project on Windows 11 with
Python 3.12. Validate commands, paths, expected outputs and limitations.

Reject unsupported claims such as guaranteed convergence, guaranteed hovering,
or results that have not been generated. Ensure plots and videos are linked
only if they exist. Keep the README concise, technical and portfolio-ready.
