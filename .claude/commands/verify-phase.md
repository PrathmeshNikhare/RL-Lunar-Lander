---
description: Verify the active phase against its acceptance criteria.
---

Read the active phase specification and inspect the actual implementation.
Run only relevant, safe checks. Separate:
- passed checks with command and evidence;
- failed checks with error summary;
- not-run checks and why;
- acceptance criteria met/not met;
- review findings and remaining risks.

Do not modify implementation during verification unless the user explicitly
asks for fixes. Never mark a phase complete with unresolved required criteria.
