# Handoff — 2026-11-04 — Phase 03

## Summary
Phase 03 (reward wrapper) is implemented and verified. It delivered:
- four validated reward modes: `original`, `time_penalty`,
  `upright_slow_bonus`, `potential_based`;
- pure reward functions, separate from the wrapper;
- `RewardComponentsWrapper`, applied in training outside SB3's `Monitor`, so
  the monitor logs keep the original reward;

  `reward/*`);
- `docs/reward-wrapper.md`: formulas, units, terminal handling and the
  assumptions behind policy invariance.

No training runs or experiment configs were added; those belong to Phase 04.
The parameter values in tests and docs are placeholders.
