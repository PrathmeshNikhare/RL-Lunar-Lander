# Phase 06 — Visualization and Analysis

## Objective
Produce clear, truthful visuals and a concise experiment analysis.

## Tasks
- Plot training curves with run/seed distinctions.
- Plot evaluation return distributions or mean with variability.
- Plot success/crash rates and episode lengths.
- Visualize reward component accumulation.
- Include representative videos where available.
- Write an analysis of observed behaviours, limitations and unexpected results.

## Acceptance criteria
- Every graph is generated from saved result data.
- Axes, units, sample sizes and reward definitions are clear.
- No fabricated or hand-edited performance claims.
- Videos correspond to recorded runs and are labeled accurately.
- Analysis explains both positive and negative outcomes.

## Verification
Re-run analysis from saved data and inspect outputs.

## Review
Experiment Analyst + Documentation Reviewer.

this phase. Run the specified checks, request the listed specialist review,
update progress files and create a handoff. Ask for approval before advancing.
