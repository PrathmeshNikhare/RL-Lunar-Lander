# Phase 07 — GitHub Publication

## Objective
Prepare a polished, reproducible portfolio repository.

## Tasks
- Complete README with problem, architecture, setup, commands and results.
- Document reward formulas and experiment protocol.
- Include architecture diagram and selected plots/videos.
- Verify clean install instructions on Windows.
- Audit Git history, ignored files, secrets and artifact sizes.
- Add limitations and future work.
- Run complete non-training test suite and static checks.
- Prepare release summary.

## Acceptance criteria
- A new contributor can reproduce the workflow from README.
- All published results are backed by artifacts and metadata.
- No secrets or machine-specific paths are present.
- Tests/checks and their results are documented.
- User approves final publication.

## Verification
Clean-environment setup walkthrough, test suite, static checks, Git audit.

## Review
Documentation Reviewer + Architecture Reviewer + Test Engineer.

## Execution instructions

First produce a plan only. Do not edit until the user approves. Implement only
this phase. Run the specified checks, request the listed specialist review,
update progress files and create a handoff. Ask for approval before advancing.

## Required phase report

Record: files changed, commands run, test results, review findings, acceptance
criteria evidence, unresolved issues, Git checkpoint and next action.
