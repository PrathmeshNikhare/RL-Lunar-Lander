# Portfolio Release Checklist

- [ ] README explains problem, approach, setup, experiments and results.
- [ ] Architecture diagram matches the implementation.
- [ ] Installation tested on Windows 11 / Python 3.12.
- [ ] Training and evaluation commands are reproducible.
- [ ] Reward equations and limitations are documented.
- [ ] Evaluation uses original environment reward.
- [ ] Results include multiple seeds or explain why not.
- [ ] Graphs are generated from retained data.
- [ ] Videos are real outputs from this project.
- [ ] No secrets, local paths or unnecessary large artifacts.
- [ ] Tests and static checks pass.
- [ ] Known limitations and future work are honest and specific.
